# DesignOS UXEval — 设计师内测指南

> 给团队内部设计师，**5 分钟上手**

---

## 一、一次性准备（5 分钟）

### 方式 1：pip 安装（推荐）

```bash
# 安装 designos
pip3 install designos

# 初始化（自动配 API Key + 修复 PATH）
python3 -m designos init
```

> `designos init` 会自动把命令加入 PATH。之后新开终端就能直接用 `designos` 命令。
> 如果当前终端提示 command not found，用 `python3 -m designos` 代替即可。

### 方式 2：从源码（开发者 / 需要改代码）

```bash
git clone git@github.com:Eryooo/designos.git ~/Documents/designos
cd ~/Documents/designos

# 装 uv（如果没装过）
curl -LsSf https://astral.sh/uv/install.sh | sh

# 装项目依赖
~/.local/bin/uv sync
```

### 配 API Key

`designos init` 会交互式引导你配置。也可以手动：

```bash
mkdir -p ~/.designos
cat > ~/.designos/.env.local << 'EOF'
ANTHROPIC_API_KEY=sk-xxx
ANTHROPIC_BASE_URL=https://one.iflytek.com/api/llm/console/chat
EOF
```

> Trae / 沙箱环境：如果 `~/.designos` 不可写，设置环境变量 `DESIGNOS_HOME=./.designos` 即可。

## 二、日常使用（90% 不需要敲命令）

### 方式 A：IDE 内对话（推荐）

**Trae / Claude Code / Cursor / Codex / Workbuddy / Codebuddy 用户都这样**：

1. **在 IDE 里打开 `~/Documents/designos` 目录**（IDE 会自动读 `AGENTS.md`）
2. **新建一个项目子目录**，把 PRD 和截图放进去：
   ```
   ~/Documents/designos/work/新版工作台评估/
   ├── inputs/
   │   ├── prd.md          ← 你的 PRD
   │   ├── scope.md        ← 评估范围（见下方模板）
   │   └── screens/        ← 产品截图（可选）
   ```
3. **对 AI 说一句话**：

   > 「请用 uxeval skill 评估我在 `work/新版工作台评估/` 下的产品，客户端模式」

   或更短：

   > 「/uxeval 客户端模式 work/新版工作台评估」

4. AI 会按 12 阶段自动执行：
   - PRD 理解 → 用户角色 → 场景 → 启发式原则
   - 旅程图 → **暂停问你「旅程对吗？」**
   - 任务清单 → **暂停问你「任务清单对吗？」**
   - 截图分析 → 启发式检测 → 问题归因 → **暂停问你「严重等级对吗？」**
   - 输出 Excel 报告

5. **三个暂停点**你只需回复"继续 / 修改 / 补充"。

---

### 方式 B：命令行（适合工程师 / 批量跑）

```bash
# 1. 创建工作区
cd /tmp
designos init 我的项目 --skill uxeval
# 如果 designos 命令找不到，用：python3 -m designos init 我的项目 --skill uxeval

# 2. 放好 inputs/ 资料后跑
cd 我的项目
designos run uxeval --mode client --auto-confirm

# 3. 查产出
ls runs/001-uxeval/outputs/
```

## 三、`scope.md` 模板（必填）

复制粘贴到 `inputs/scope.md`，填空：

```markdown
# 评估范围

## 评估目标
（一句话：你要验证什么。比如「验证新版工作台对数据分析师能否高效完成日常任务」）

## 产品范围
- 范围内：（哪些模块/功能在评估内）
- 范围外：（哪些不评估）

## 关键用户角色
- 角色 A：（一句话职责 + 痛点）
- 角色 B：（同上）

## 业务背景（可选）
（业务目标、KPI 等）
```

## 五、常见问题

### 1. AI 在 IDE 里没识别 uxeval skill？

确认你在 IDE 里打开的目录是 `~/Documents/designos`（含 `AGENTS.md` 的目录）。如果在子目录打开，把 `AGENTS.md` 复制一份到子目录。

### 2. 跑到中间断了

```bash
# IDE 里：对 AI 说「继续刚才的评估」
# 命令行：加 --run-id 参数
~/Documents/designos/.venv/bin/python -m designos.cli.main run uxeval --mode client --auto-confirm --run-id 001-uxeval
```

### 3. 评估方向跑偏（变成功能测试）

在 Checkpoint 时回复"修改"，告诉 AI：
> 「目前的任务清单偏功能测试了，请按"用户能否完成 XX 任务"重写」

### 4. 截图没法提供（客户端登录不了）

写一份 `inputs/screens-description.md`，文字描述每个页面的关键元素。AI 会把它当虚拟截图处理。模板：

```markdown
# 截图描述

### 工作台-首页
- 顶部导航：Logo / 工作台 / 数据治理 / 设置
- 左侧侧边栏：3 级菜单
- 主区域：12 条待办（无视觉分类）
- 痛点：信息过载，无法快速定位
```

### 5. principle-mapping 阶段慢（2-3 分钟）

正常。这是 LLM 在生成完整启发式映射，输出量大。耐心等。

### 6. Excel 报告路径

默认在 `/tmp/issue_report_<时间戳>.xlsx`。想自定义，在 Checkpoint C3 告诉 AI：
> 「Excel 输出到 outputs/我的报告.xlsx」
