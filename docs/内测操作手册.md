# DesignOS UXEval 内测操作手册

> 版本：v0.1（M1 内测版）
> 适用人群：团队内部设计师
> 前置条件：macOS，Python 3.11+

---

## 一、首次安装（10 分钟，只做一次）

### 1. 克隆仓库

```bash
cd ~/Documents
git clone git@github.com:Eryooo/designos.git
cd designos
```

### 2. 创建虚拟环境 + 安装依赖

```bash
~/.local/bin/uv sync
```

如果没有 uv，先装：
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

### 3. 配置 API Key

```bash
cp .env.example ~/.designos/.env.local
```

编辑 `~/.designos/.env.local`，填入：
```bash
ANTHROPIC_API_KEY=你的API密钥
ANTHROPIC_BASE_URL=https://one.iflytek.com/api/llm/console/chat  # 集团代理地址
```

### 4. 验证安装

```bash
.venv/bin/python -m designos.cli.main version
# 应输出：DesignOS 0.1.0
```

## 二、每次使用（5 分钟准备 + 6-8 分钟执行）

### Step 1：创建项目工作区

```bash
cd /tmp  # 或你喜欢的任何位置
PYTHONPATH=~/Documents/designos \
  ~/Documents/designos/.venv/bin/python -m designos.cli.main init 我的项目名 --skill uxeval
```

会生成：
```
我的项目名/
├── inputs/          ← 你放资料的地方
├── outputs/
├── runs/
└── designos.project.yaml
```

### Step 2：准备输入资料

把以下文件放到 `inputs/` 目录：

| 文件 | 必需？ | 说明 |
|---|---|---|
| `prd.md` | ✅ 必需 | 产品 PRD（Markdown 格式，PDF 也行改名 .md） |
| `scope.md` | ✅ 必需 | 评估范围（见下方模板） |
| `screens/` 目录 | 推荐 | 产品截图（.png/.jpg），至少 5 张 |

**scope.md 模板**（复制后填写）：
```markdown
# 评估范围

## 评估目标
验证 XXX 产品对 XXX 用户的体验质量。

## 产品范围
- 范围内：XXX 模块、XXX 功能
- 范围外：XXX

## 关键用户角色
- 角色 A：每天使用 X 小时，关注 XXX
- 角色 B：偶尔使用，关注 XXX
```

### Step 3：执行评估

```bash
cd 我的项目名

ANTHROPIC_API_KEY=你的密钥 \
ANTHROPIC_BASE_URL=https://one.iflytek.com/api/llm/console/chat \
PYTHONPATH=~/Documents/designos \
  ~/Documents/designos/.venv/bin/python -m designos.cli.main run uxeval --mode client --auto-confirm
```

**执行过程**（约 6-8 分钟）：
```
Running skill 'uxeval' (run_id=001-uxeval) …
  → prd-understanding        ✓ (~7s)
  → persona-derivation       ✓ (~5s)
  → scenario-derivation      ✓ (~27s)
  → principle-mapping        ✓ (~150s)  ← 最慢，耐心等
  → journey-modeling         ✓ (~14s)
  → task-generation          ✓ (~24s)
  → screenshot-loading       ✓ (<1s)
  → heuristic-detection      ✓ (~71s)
  → issue-attribution        ✓ (~60s)
  → report-generation        ✓ (<1s)
Run complete.
```

### Step 4：查看产出

产出在 `runs/001-uxeval/outputs/`（如果 pipeline 写了文件）和 `/tmp/issue_report_*.xlsx`。

当前 M1 版本的主要产出是 **LLM 生成的结构化文本**（旅程图、任务清单、问题清单），保存在 pipeline state 中。完整 Excel 报告在 `/tmp/` 下。

## 三、两种模式说明

| 模式 | 适用场景 | 输入要求 |
|---|---|---|
| `--mode client` | 客户端应用 / 无法自动登录的产品 | 用户提供产品截图到 `inputs/screens/` |
| `--mode web` | Web 应用（M2 才完整支持） | 需要 Playwright + 产品 URL + 账号密码 |

**M1 内测请用 `--mode client`**。

## 四、常见问题

### Q: 报错 "ANTHROPIC_API_KEY is not set"
A: 确认环境变量设置正确。可以在命令前加 `ANTHROPIC_API_KEY=xxx`。

### Q: 报错 "skill not found: uxeval"
A: 确保 `PYTHONPATH` 指向 designos 仓库根目录，或者把 `skills/uxeval` 复制到工作区的 `.claude/skills/` 下：
```bash
mkdir -p .claude/skills
cp -r ~/Documents/designos/skills/uxeval .claude/skills/
```

### Q: principle-mapping 阶段特别慢（2-3 分钟）
A: 正常。这个阶段 LLM 要生成完整的启发式原则映射，输出量大。

### Q: 中途断了怎么办
A: 重新跑即可（`--run-id 001-uxeval` 会从 checkpoint 恢复）：
```bash
ANTHROPIC_API_KEY=xxx PYTHONPATH=~/Documents/designos \
  ~/Documents/designos/.venv/bin/python -m designos.cli.main run uxeval \
  --mode client --auto-confirm --run-id 001-uxeval
```

### Q: 想评估另一个产品
A: 新建一个工作区：
```bash
PYTHONPATH=~/Documents/designos \
  ~/Documents/designos/.venv/bin/python -m designos.cli.main init 另一个项目 --skill uxeval
```
