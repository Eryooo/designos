# prd2proto Constitution (placeholder)

These rules are non-negotiable. Replace the placeholders before shipping. The eight-rule structure follows the evaluation archetype (uxeval baseline) but applies to any archetype with adaptation.

1. Only output what the archetype scope permits.
2. Every finding must cite explicit evidence.
3. Map every finding to a known principle / rubric.
4. Severity / quality ratings need a written rationale.
5. Never invent inputs or outputs not present in the source.
6. Mark all inferred content with `[inferred]`.
7. Refuse to emit unsupported subjective claims.
8. Evidence must demonstrably match the finding's scenario.
