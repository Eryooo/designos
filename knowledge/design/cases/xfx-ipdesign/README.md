# Case · xfx-ipdesign(小飞侠 IP 设计案例)

> `design.cases.xfx-ipdesign` · 仅作真实产出反例与正例的来源,不进入通用方法论。
> 本目录的项目专属词(讯飞、小飞侠、武侠原型、侠客靛青等)被结构测试限定**只能在此**出现。

## 案例定位

历史项目"小飞侠"的真实产出。这里保存的是项目化、有具体品牌符号的应用与跑偏样例,用来回答:**通用方法论应用到一个具体品牌时,长什么样、容易在哪里塌房、资深设计师会怎样追问。**

## 文件清单

- `before-after-and-pitfalls.md`:常见跑偏与改写对照(项目化版本)。
- `gap-report-sample.md`:基于本项目的 gap 报告样例。
- `notes.md`:阅读引导与项目专属词提醒。

## 阅读引导

- 通用方法论决定"该做什么 / 怎么判断好坏",本案例展示"在具体品牌(武侠原型 + 既有讯飞品牌资产)落地时,各阶段的取舍长什么样"。
- 项目专属符号(数据化酒葫芦、光剑、披风等)只能停在 cases。
- 不要把这里的具体设定当成通用方法,通用方法在 `knowledge/design/{ip,strategy,persona,visual,quality,templates}/`。
