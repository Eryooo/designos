# Before / After 与跑偏样例 · xfx-ipdesign

> 本文档基于真实"小飞侠"项目反推。所有项目专属词(小飞侠 / 讯飞 / 武侠 / 侠客靛青等)**只能在 cases 出现**;通用方法论里不允许复制这些。

## 1. 北极星功能化 → 情感价值

**Before(失败模式 F-S1):**
> "小飞侠帮员工调用集团 AI 能力。"

只有功能动作,没有情感/体验价值,违反 M01 必过项。

**After:**
> "让员工像点按钮一样调用集团 AI 能力,把复杂办公任务快速变成可用结果。"

含五要素(用户对象 = 员工 / 方式 = 点按钮 / 能力 = 调用 AI / 价值 = 复杂变简单 / 结果 = 可用输出),且落在体验价值。

## 2. 仅 MBTI 标签 → 行为模式 + MBTI 辅助

**Before(失败模式 F-P1):**
> "小飞侠是 ESTJ 总经理型。"

只有 MBTI 标签,无可观测行为模式。

**After:**
> 行为模式序列:识别需求 → 拆解任务 → 执行调度 → 结果提升。每步给可观测信号(主动扫描工作环境 / 分解为子任务 / 协调多 Agent / 呈现可用成果)。
> MBTI 仅作辅助语言:E 主动识别 / S 关注实际结果 / T 按规则执行 / J 任务闭环导向。

## 3. 视觉无基因继承 → 三栏继承表

**Before(失败模式 F-V1):**
> 直接给小飞侠设计了一套与讯飞既有品牌资产无关的色彩与符号。

**After:**
| 继承(不可动) | 新增(IP 专属) | 禁冲突 |
|---|---|---|
| 讯飞蓝主色 | 数据化酒葫芦(主符号)、光剑(辅)、披风 | 不改主色调、不与既有讯飞 logo 形态冲突 |

## 4. 32px 糊掉 → 四级简化

**Before(失败模式 F-V2):**
> 只画了一套标准尺寸,放到 32px 系统托盘时形象糊掉,认不出。

**After:**
- 大(≥128px):完整侠客形象 + 披风 + 酒葫芦细节。
- 中(48–128px):弱化披风纹理,保留酒葫芦与剪影。
- 小(24–48px):退化为酒葫芦 + 披风轮廓 + 主色块。
- 极小(<24px):单酒葫芦剪影 + 单一主色。

四级共用同一识别符号(酒葫芦),不同识别强度而已。

## 5. 提示词单段自由描述 → 四层 + 负向

**Before(失败模式 F-PR1 + F-PR3):**
> "画一个武侠风格的 AI 助理 IP,有酒葫芦,科技感。"

无分层、无量化、无负向项,跑偏频繁(变 3D / 二次元 / 写实人物)。

**After(四层结构):**
1. 核心符号定位:数据化酒葫芦(主符号 ~70%)+ 光剑(辅 ~20%)+ 披风(状态指示 ~10%)。
2. 设计理念:极简符号化 / 文化-现代融合 / 多场景适配。
3. 技术参数:主色讯飞蓝 70% + 青绿 20% + 金色 10%;毛玻璃 70% 透明度;输出 4K PNG 透明背景。
4. 质量与避免:32px 下酒葫芦清晰可辨;严格避免:过度 3D / 写实人物 / 二次元 / 魔法师 / 文字水印 / 拉伸变形。
