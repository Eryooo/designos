# Gap 报告样例 · xfx-ipdesign

> 基于真实"小飞侠"项目状况反推的 gap 报告范例,展示`design.quality.professional-gap-report`如何使用。

## 总声明

本产出存在 3 个未关闭 gap,其中 0 个涉及一票否决项;整体放行结论:**中阶可用,涉及对外印刷物料前需补足 GAP-V-001 与 GAP-M-001**。

## GAP-S-001 用户画像证据弱

- **stage / dimension**:M01 / D9 跨阶段证据
- **现状**:用户画像基于内部经验描述,无真实研究数据;典型一天与痛点为推断。
- **缺位原因**:项目周期紧,未投入用户研究。
- **达到中阶所需补充**:补 5–10 名目标用户的访谈或日记法记录,验证痛点真实性,推断转事实。
- **临时放行边界**:可用于内部讨论与方向对齐;不可用于对外品牌发布或市场宣传。

## GAP-V-001 印刷色彩 Pantone 未确认

- **stage / dimension**:M04 → M06 / D5 落地成本
- **现状**:视觉规范给了讯飞蓝十六进制值,但未做 Pantone 配色与打样验证;实物物料(玩偶/印刷海报)可能出现严重偏色。
- **缺位原因**:无打样预算,Pantone 系统未引入。
- **达到中阶所需补充**:与品牌方/印厂确认 Pantone 编号,做小批量打样,记录 RGB ↔ Pantone 实际偏差。
- **临时放行边界**:屏幕端物料可继续使用;一切印刷类物料在补足前不放行。

## GAP-M-001 衍生品成本评估缺失

- **stage / dimension**:M06 / D5 落地成本
- **现状**:衍生品清单含"光效披风毛绒玩具"等复杂工艺,但未评估可落地性与成本档位。
- **缺位原因**:与代工厂沟通未启动。
- **达到中阶所需补充**:每条衍生品补 `feasibility` 与 `cost_band`;与 ≥2 家代工厂询价后修订清单,删除不可落地或成本失控项。
- **临时放行边界**:可用作概念清单与品牌讨论;不可作为采购下单依据。
