# Before / After 与跑偏样例 · xfg-ip-kimi

> 基于真实"小飞棍"项目反推。所有项目专属词(讯飞/小飞棍/效率权杖/深空灰/活力橙等)**只能在 cases 出现**。

## 1. 视觉跑偏(3D/二次元) → 风格谱系坐标 + 严格避免

**Before(失败模式 F-V4):**
> 提示词只写"科技感企业 AI 助理 IP",AI 频繁出 3D 写实/卡通萌系,与品牌成熟商务风冲突。

**After(锁定风格坐标 + 负向):**
- 风格谱系坐标:
  - 扁平 ↔ 拟物 → **扁平**
  - 几何 ↔ 有机 → **几何**
  - 极简 ↔ 繁复 → **极简**
  - 成熟商务 ↔ 萌系 → **成熟商务**
  - 2D ↔ 3D → **2D**
- 严格避免:过度 3D / 复杂机械 / 动物特征 / 二次元/萌系 / 魔法师元素 / 多余装饰 / 文字水印。

## 2. 提示词模糊词导致不稳定 → 全量化 + 锁定

**Before(失败模式 F-PR2):**
> "深空灰主色,有点科技感的橙色强调,披风飘动幅度适中。"

模糊词("有点""适中")导致每次出图差异大。

**After(全量化):**
- 主色:深空灰 #1A1A2E (60%)
- 强调:活力橙 #FF6B35 (30%)
- 辅助:科技蓝 #3A86FF (10%)
- 披风幅度:缩放 ≤ 30%(防变形)
- 动效时长:点 300ms / 挥 500ms / 成 400ms

锁定项:`primary_hex = #1A1A2E`、`core_symbol_name = 效率权杖`、`style_position = 扁平+几何+极简+成熟商务+2D`。

## 3. 三视图各画各 → 基准图 + 一致性检查点

**Before(失败模式 F-PR4):**
> 正面/侧面/背面分别独立提示词,各次出图主形/比例/色相飘移。

**After:**
- 先生成 1 张基准图(正面)→ 锁定核心符号定义与色值。
- 三视图衍生:仅改姿态(侧面 45° 倾斜 / 背面披风占 70% 面积),核心符号与色值不变。
- 一致性检查点:符号同形 ✓ / 主色同值 ✓ / 风格坐标未漂移 ✓。

## 4. 状态延展只有"待机/活跃" → 完整状态序列

**Before(失败模式 F-V3 风格漂移变体):**
> 设计稿只给了"待机"和"活跃"两个状态,执行/失败时画面无规范,各 PM/前端各画各。

**After(6 状态序列,与情绪 + 时长对齐):**
| 状态 | 视觉表现 | 时长/周期 | 应用场景 | 绑定情绪 |
|---|---|---|---|---|
| 待机 | 单线眼微亮 + 状态灯呼吸 | 循环 | 空闲 | 平静 |
| 激活 | 圆点眼亮起 + 权杖亮起 | 一次性 ~300ms | 任务接收 | 专注 |
| 执行 | 圆点眼闪烁 + 权杖射出光点 | 循环 | 处理中 | 投入 |
| 确认 | 眨眼 + 屏障出现 | 一次性 ~500ms | 等待人工确认 | 谨慎 |
| 完成 | 弯月眼 + 光点汇聚成勾选 | 一次性 ~400ms | 任务完成 | 满足 |
| 失败 | 下垂线 + 权杖回收 + 红色提示 | 一次性 ~400ms | 执行失败 | 反思但不慌 |

每个状态与 voice-and-behavior.emotion_expressions 对齐,语言与画面不会错位。

## 5. 衍生品过度复杂 → 可落地性 + 成本档位

**Before(失败模式 F-M1):**
> 衍生品清单包含"多层结构 + 内置发光 + 动态披风"的 PVC 手办,工艺复杂,代工厂报价远超预算。

**After:**
- 删除不可落地项;复杂工艺降级为简化版本。
- 每条加 `feasibility / cost_band`:
  - 贴纸/徽章 → 高可落地 / 低成本
  - 毛绒玩具(简化版) → 可落地 / 中成本
  - 多层动态手办 → 不可落地(本期),延后到 v2
