# Gap 报告样例 · xfg-ip-kimi

> 基于真实"小飞棍"项目反推的 gap 报告样例。

## 总声明

本产出存在 2 个未关闭 gap,其中 0 个涉及一票否决项;整体放行结论:**中阶可用,屏幕端可继续推进;印刷类与采购类物料在补足 GAP-V-002、GAP-M-002 之前不放行**。

## GAP-V-002 多平台一致性未跨平台验证

- **stage / dimension**:M04 提示词 / D7 提示词可控性
- **现状**:四层提示词在即梦 AI 已验证稳定,但在 Stable Diffusion 与 Midjourney 仅做了语义等价改写,未跑足够轮次验证负向 prompt 的实际拦截率。
- **缺位原因**:跨平台测试预算不足。
- **达到中阶所需补充**:每平台跑 ≥20 轮基准图,记录跑偏率与负向 prompt 命中率,迭代负向项至跑偏率 < 10%。
- **临时放行边界**:即梦端可正常使用;SD/MJ 端仅作内部探索,产出不直接用于对外物料。

## GAP-M-002 印刷物料 Pantone + 打样未完成

- **stage / dimension**:M06 / D5 落地成本
- **现状**:活力橙 #FF6B35 与深空灰 #1A1A2E 已有 RGB 值,但未确认 Pantone,未做打样验证。
- **缺位原因**:与印厂沟通未启动。
- **达到中阶所需补充**:与品牌方/印厂确认 Pantone 编号,打样 ≥3 个核心物料(海报/玩偶吊牌/徽章),记录偏色并修订物料规格。
- **临时放行边界**:屏幕端、社交媒体物料可继续使用;海报/印刷品/实物周边在补足前不下印。
