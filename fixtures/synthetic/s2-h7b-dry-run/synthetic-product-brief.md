# [SYNTHETIC] Acme Corp Task Manager Product Brief

**状态**: SYNTHETIC / SANITIZED

## 产品概述

Acme Corp Task Manager 是一个面向中小团队的协作任务管理 SaaS。

## 目标用户

- **主要用户**: 5-20 人的产品开发团队
- **角色**: 项目经理、产品经理、开发工程师
- **痛点**: 现有工具过于复杂，学习成本高

## 核心价值主张

让小团队用最简单的方式协作任务，3 分钟上手，无需培训。

## 关键特性

1. 看板视图
2. 任务分配与状态跟踪
3. 简单权限管理
4. Slack / 邮件通知

## 品牌调性

- 轻松、友好、不装腔作势
- 强调"简单"而非"强大"
- 目标是"好用"，不是"功能全"

## 故意制造的一致性缺口（用于触发 consistency gate）

注意：此处 target audience 描述为"5-20 人的产品开发团队"，但在 `synthetic-prd.md` 中的 user role 会描述为"10-50 人的项目团队"，形成轻微不一致，用于验证跨 skill consistency contract 是否能捕获。

- 真实客户名称
