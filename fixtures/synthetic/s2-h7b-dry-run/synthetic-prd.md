# [SYNTHETIC] Acme Task Manager PRD v1.0

**状态**: SYNTHETIC / SANITIZED

## 产品目标

构建一个简单易用的任务管理工具，帮助中小团队高效协作。

## 目标用户

- **主要角色**: 项目经理、产品经理
- **次要角色**: 开发工程师、设计师
- **团队规模**: 10-50 人的项目团队

注意：此处"10-50 人"与 `synthetic-product-brief.md` 的"5-20 人"存在轻微不一致，用于触发 consistency gate。

## 用户故事

1. 作为项目经理，我希望快速创建任务并分配给团队成员
2. 作为开发工程师，我希望看到我的所有待办任务
3. 作为产品经理，我希望查看项目整体进度

## 功能需求

### 1. 任务管理
- 创建任务（标题、描述、优先级）
- 分配任务给成员
- 修改任务状态（待办、进行中、已完成）

### 2. 看板视图
- 三列看板：待办、进行中、已完成
- 拖拽改变任务状态
- 筛选与搜索

### 3. 权限管理
- 管理员可以邀请成员
- 成员可以查看与编辑自己的任务
- 访客只读权限

## 非功能需求

- 响应时间 < 200ms
- 移动端适配
- 支持 Chrome / Safari / Firefox
